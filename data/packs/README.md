# Паки атрибутики

Пак — это слой данных, который решает, **чей** это матч. Всё, что делает игру
«Бразилия — Франция, Стад де Франс, 1998», собрано здесь, а не в коде: названия
команд, фамилии, формы, рекламные щиты, рисунок мяча, подпись стадиона.

Зачем — [База-знаний/Исследования/17-Юридика-после-релиза-и-YouTube.md](../../База-знаний/Исследования/17-Юридика-после-релиза-и-YouTube.md).
Коротко: играем и разбираем историю с реальной атрибутикой, а публикуем и снимаем
ролики на чистой. Переключение — одна строка, логика не трогается.

## Что где

| Пак | Что внутри | Куда годится |
|---|---|---|
| `wc98-real` | Реальные фамилии, формы с эмблемами, щиты Coca-Cola / adidas / Canon / FUJIFILM / PHILIPS / McDonald's, мяч Tricolore, «Стад де Франс» | Свои сборки, тесты, разбор истории. **Не для публичного релиза и не для YouTube** |
| `retro-legends` | Искажённые фамилии (Роналдо → Роландо), «БРАЗИЛИА» и «ГАЛЛИЯ», формы без эмблем и полос производителя, выдуманные щиты эпохи, классический мяч | Публичный релиз, ролики, всё видимое снаружи |

## Как переключить

Постоянно — `data/packs.json`:

```json
{ "active": "retro-legends" }
```

Разово, не трогая файл, — параметр в адресе:

```
https://olegk77777.github.io/retro-soccer/?pack=retro-legends
```

Так удобно записывать ролики: ссылка сразу открывает чистую версию.

## Как правится состав

**Источник истины — только `wc98-real`.** Публичный пак собирается из него
скриптом и руками не редактируется (он и помечен `_собрано`).

1. Правишь `data/packs/wc98-real/teams/*.json`.
2. Правишь псевдонимы в `data/packs/retro-legends/aliases.json`, если появились новые фамилии.
3. Пересобираешь:

```bash
node tools/build-anon-pack.mjs
```

Скрипт **специально падает**, если у игрока нет псевдонима, и называет его: иначе
реальная фамилия молча уехала бы в публичный билд.

## Формат pack.json

```json
{
  "id": "wc98-real",
  "title": "ЧМ-98 · ФИНАЛ",
  "licensing": "real",
  "venue": "СТАД ДЕ ФРАНС · СЕН-ДЕНИ · 12 ИЮЛЯ 1998",
  "teams": { "home": "teams/home.json", "away": "teams/away.json" },
  "textures": {
    "boards": "./textures/stadium/ads-france-98.png",
    "ball": "./textures/ball/tricolore-98.png",
    "channelLogo": "./textures/tv/ut1-white.svg"
  }
}
```

- `licensing` — `real` или `clean`. Пометка для человека, код её не читает.
- `teams` — пути **относительно папки пака** (это его собственные данные).
- `textures` — пути **от корня сайта** (ресурсы общие для всех паков).
- `boards: null` — остаются процедурные щиты с выдуманными марками эпохи
  (СПОРТ·ТВ, КИНЕСКОП, ВОЛНА, ЭФИР 98, МЕТЕОР, ОРБИТА·888) из `src/scene.js`.
- `ball: null` — остаётся классический чёрно-белый мяч из `src/ball.js`.
- `channelLogo` — «жучок» телеканала в левом верхнем углу кадра. У своей
  сборки настоящий `ut1-white.svg` (УТ-1 образца 1991–1997), у публичной
  вымышленный `ug1-white.svg` («УГ-1»). Рядом лежат чёрные версии обоих
  (`ut1.svg`, `ug1.svg`) — на случай светлого фона. `null` — жучка нет вовсе.
  Логотипы каналов — такая же охраняемая марка, как эмблема клуба: в публичный
  билд идёт только выдуманный.
